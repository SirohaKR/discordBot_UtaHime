💬 프롬프트 추천 채널

지정된 채널에 문장(또는 이미지)을 그냥 올리면 AI가 어울리는 Danbooru 태그를 추천해줍니다. 이미지만 첨부하면 그 이미지를 보고 태그를 뽑아주고, 텍스트도 같이 있으면 텍스트 요청을 우선 반영합니다.

명령어설명
/프롬프트채널설정현재 채널을 프롬프트 추천 전용 채널로 지정합니다 (관리 명령).
/프롬프트채널설정해제지정을 해제합니다.
여기서 추천받은 태그는 NovelAI·PixAI 같은 그림 생성 사이트에 그대로 붙여넣어 쓰면 됩니다 (이 봇이 그림을 직접 그리지는 않아요). 요청 사이엔 5초 쿨다운이 있습니다.

🗨️ 자유 채팅 채널

지정한 채널에서는 명령어 없이 그냥 편하게 말을 걸면 Claude가 답장합니다. 하는 일은 일상 대화와 그림 프롬프트 추천 두 가지예요 — 그리고 싶은 그림 얘기를 하면 대화로 아이디어를 다듬고 태그를 추천해줍니다. 실제 그림은 그 태그를 그림 생성 사이트에 붙여넣어서 만드세요.

페르소나는 "시로챤넬"의 서포트 AI "란다" — 사용자를 "회원님"이라고 부르는 장난기 있는 성인 메이드 캐릭터입니다. 성인끼리의 서버라 욕설·19금 농담·성인 주제도 훈계 없이 편하게 받아줘요. 이미지를 첨부하면 보고 코멘트하거나 태그를 뽑아줍니다. 대화 기억은 채널별로 최근 30턴 정도 메모리에 보관되고 봇 재시작 시 초기화됩니다. 유저별 5초 쿨다운이 있습니다.
명령어설명
/채팅채널설정현재 채널을 자유 채팅 채널로 지정합니다 (관리 명령).
/채팅채널설정해제지정을 해제합니다.
/채팅초기화이 채널에서 봇과 나눈 대화 기억을 초기화합니다.
/가이드어디서나 사용 가능. 봇의 전체 기능을 정리한 임베드를 보여줍니다.

🗣️ TTS (글 읽어주기)

TTS 채널로 지정된 텍스트채널에 글을 쓰면, 쓴 사람이 들어가 있는 음성채널에서 봇이 소리로 읽어줍니다. 초성체(ㅋㅋ, ㄹㅇ 등)도 자연스럽게 읽어요. 음악이 재생 중일 땐 노래를 끊지 않도록 TTS는 건너뜁니다.

명령어설명
/목소리설정내 메시지를 읽어줄 목소리를 고릅니다. 이름/성별/나이로 검색 가능 (자동완성, 타입캐스트 목소리 포함).
/내목소리지금 내 메시지를 읽는 목소리를 확인합니다.
/목소리초기화개인 설정을 지우고 서버 기본 목소리로 돌아갑니다.
/목소리미리듣기목소리를 mp3로 미리 들어봅니다.
/tts채널설정현재 채널을 TTS 채널로 지정합니다 (관리 명령).
/tts채널해제TTS 채널 지정을 해제합니다 (관리 명령).
/tts기본목소리개인 설정이 없는 사람에게 쓰일 서버 기본 목소리를 정합니다 (관리 명령).

🔊 음성 허브 (자동 음성방)

허브로 지정된 음성채널에 들어가면 내 음성방이 자동으로 만들어지고 그쪽으로 옮겨집니다. 방이 비면 자동으로 삭제돼요. 이름 규칙에서 {user}는 들어온 사람 이름, {n}은 빈 번호(1, 2, 3...)로 바뀝니다.

명령어설명
/음성허브추가음성채널을 허브로 지정합니다. 이름 규칙(예: {user}의 방, 개인방 {n})과 최대 인원을 정할 수 있어요 (관리 명령).
/음성허브삭제허브 지정을 해제합니다 (관리 명령).
/음성허브목록지정된 허브 목록을 확인합니다.

🎵 음악 재생

유튜브 검색/링크로 음성 채널에서 음악을 재생합니다. 명령어 접두사(!)와 슬래시(/) 둘 다 지원됩니다.

설정 & 입장

명령어설명
/설정현재 채널을 음악 전용 채널로 지정하고, 재생을 조작할 컨트롤러 메시지를 게시합니다 (관리 명령).
/join전용 채널에서 봇을 사용자의 음성 채널로 불러옵니다.
/leave대기열을 비우고 음성 채널에서 퇴장합니다. stop

재생 & 플레이리스트

명령어설명
/play검색어 또는 유튜브 링크를 대기열에 추가합니다. 실행p
/플레이리스트추가유튜브 링크를 이름 붙여서 저장합니다. pladd
/플레이리스트목록저장된 플레이리스트 목록을 확인합니다. pllist
/플레이리스트삭제저장된 플레이리스트를 삭제합니다. pldel
/volume볼륨을 조회하거나 설정합니다. 숫자(30)로 절대값, +10/-20으로 상대 조절. vol볼륨

컨트롤러 버튼 (전용 채널에 게시된 메시지)

⏸️
일시정지 / 재개재생 상태에 따라 토글됩니다.
⏭️
스킵현재 곡을 건너뜁니다.
🔀
셔플 ON/OFF대기열 순서를 무작위로 재생할지 토글합니다.
🔁
반복 모드끔 → 전체 반복 → 한 곡 반복 순으로 클릭할 때마다 전환됩니다.
📄
대기열 보기현재 재생 중인 곡과 대기열을 보여줍니다.
🔇
정지 / 퇴장대기열을 비우고 음성 채널에서 나갑니다.

🖥️ 웹 설정 페이지

음악 관련 설정(기본 볼륨/셔플/반복 모드)과 플레이리스트는 디스코드 명령어 대신 웹페이지에서도 관리할 수 있습니다.

  • 관리자에게 받은 토큰 링크(?token=...)로 한 번 접속하면 이후엔 토큰 없이도 접근됩니다.
  • 설정 페이지에서 바꾼 값은 봇이 몇 초 안에 자동으로 반영합니다 (재시작 불필요).
  • 이 사용법 문서 페이지(/docs)는 토큰 없이도 누구나 볼 수 있습니다.
